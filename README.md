# To-Do List Web App

A simple **To-Do List** web application built with **HTML**, **CSS**, and **JavaScript**. This app allows users to:

- Add tasks
- Remove tasks
- Mark tasks as completed

## Demo

You can see your tasks, add new ones, and check them off as you complete them. Perfect for keeping your day organized!

## Features

- **Add tasks:** Quickly add tasks to your list.
- **Remove tasks:** Delete tasks that are no longer needed.
- **Check off tasks:** Mark tasks as completed to stay on top of your goals.
- **Responsive design:** Works on different screen sizes.
